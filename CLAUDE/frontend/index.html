play_circle Como usar o sistema (operador)

1
Atualizar feed Mercado Livre

Puxe pedidos/produtos do bridge 4M&C para o SQLite. Rede só nesta ação — a UI lê o cache local.

2
Ver pedidos e filas

Rail carrinho / tag FILAS → Guia Pedidos com árvore de status à esquerda. Filtre e selecione pedidos na tabela.

3
Operadores (CRUD) e filas

No header: seletor Operador + botão + CRUD para cadastrar técnicos. Pickup Pegar/Enviar existe na API; botões na tabela ainda estão em andamento (Etapa 1).

4
Conectar Bling

Rail Canais → clique no card Bling ERP → informe Client ID / Secret (e OAuth ou tokens). Status honestos: Configurado / Aguardando credenciais.

5
Mercado Livre 4M&C vs ML direto

4M&C = feed read-only de pedidos (produção hoje).
ML direto = OAuth App ID/Secret no DevCenter (separado; para etiquetas/writes após homologação).

6
Enviar para Bling (NF-e)

Selecione pedidos → botão verde na toolbar. Cria/envia pedido de venda no Bling. NF-e real só com NFE_EMIT_ENABLED=true — hoje costuma ficar bloqueada/gated.

7
O que ainda não fazer (produção física)

Não use BaseLinker como fonte de pedidos. Não confie 100% em Pick&Pack/ZPL físico até homologar impressora e webhook. Aba Expedição é para testes controlados — falhas devem aparecer no toast, sem fingir sucesso.

Alterar fila / status do pedido

Escolha a fila nativa de destino. A alteração fica só nesta sessão até a API de pickup/filas persistir no SQLite — ao recarregar, o cache volta.
